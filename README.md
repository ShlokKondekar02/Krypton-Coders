# ⚡ Krypton Coders - College Coding Society Website

Official website for **Krypton Coders**, our campus student-led coding club and developer community. Built using vanilla HTML5, modern CSS3 (custom properties, glassmorphism, responsive grid), and interactive JavaScript.

---

## 🌟 Pages & Structure

- **`index.html`**: Main landing page with club intro, dynamic typing headline, live JavaScript code sandbox, learning tracks, student coordinators, and membership application modal.
- **`events.html`**: Dedicated Events & Hackathons page featuring upcoming workshops, 24-hour campus hackathon schedule timeline, and past event recaps.
- **`projects.html`**: Showcase of student-built projects (CampusSync, AlgoPulse, KryptonBot, LeetTrack, NotesVault, DevResume) and guide on how to contribute.
- **`resources.html`**: Curated learning resources, DSA problem sheets (NeetCode / Striver), Git starter packs, and fresher roadmaps.
- **`style.css`**: Design system with responsive layout, glowing Krypton emerald neon theme, and glassmorphism cards.
- **`script.js`**: Interactive particle constellation canvas, dynamic typing effect, in-browser code sandbox execution, event filters, FAQ accordion, form validation, and toast notifications.

## 🚀 Getting Started

No build tools or installations required! Simply clone and open:

```bash
git clone https://github.com/ShlokKondekar02/Krypton-Coders.git
cd Krypton-Coders
```

### Run Locally

You can open `index.html` directly in any web browser, or serve it using Python:

```bash
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080) in your browser.

## 🛠️ Tech Stack

- **Structure**: HTML5 (Semantic elements & accessibility)
- **Styling**: Vanilla CSS3 (Custom properties, flexbox, CSS grid, keyframe animations)
- **Logic**: Vanilla JavaScript ES6+ (DOM manipulation, Canvas API, Event handling)
- **Icons & Fonts**: Font Awesome 6, Google Fonts (*Plus Jakarta Sans*, *Space Grotesk*, *Fira Code*)
