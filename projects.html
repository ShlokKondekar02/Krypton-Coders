How to Contribute to Club Projects

You don't need to be an expert to contribute. We have beginner-friendly issues marked for first-time contributors.

1. Fork & Clone

Visit our club GitHub organization, select any project repository you are curious about, and fork it to your personal profile.

2. Pick a "Good First Issue"

Look for tags labeled good-first-issue or help-wanted. These include minor bugfixes, documentation improvements, or simple UI tweaks.

3. Open a Pull Request

Make your changes in a branch and submit your PR. Senior members will review your code with friendly feedback and merge it!
